# 🤖 AI Photos — Telegram Bot

Telegram-бот для создания профессиональных AI-промптов и генерации изображений.  
Работает с текстом, голосовыми сообщениями и фото-референсами.

---

## ✨ Что умеет бот

- 📝 Принимает текст, голосовые сообщения и фото
- 🎤 Расшифровывает голос в текст (Whisper)
- 🖼 Анализирует загруженные фото (GPT-4o Vision)
- ❓ Задаёт уточняющие вопросы (стиль, освещение, инструмент и т.д.)
- ✍️ Генерирует профессиональный промпт на английском языке
- 🎨 Генерирует изображение по промпту (DALL-E 3)
- 💾 Сохраняет промпты и изображения по категориям
- ✏️ Обновляет промпт по правкам пользователя

---

## 🚀 Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ВАШ_АККАУНТ/Ai-photos.git
cd "Ai photos"
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Создать файл `.env`

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте ваши ключи:

```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
OPENAI_API_KEY=ваш_ключ_openai
```

#### Где взять ключи:
- **Telegram Bot Token** — создайте бота через [@BotFather](https://t.me/BotFather) → `/newbot`
- **OpenAI API Key** — получите на [platform.openai.com/api-keys](https://platform.openai.com/api-keys)

### 4. Запустить бота

```bash
python main.py
```

```

├── .env.example      # Пример переменных окружения
└── .gitignore        # Исключения для Git
```

## 💬 Сценарий использования

1. Отправьте `/start`
2. Нажмите **«Создать новый промпт»**
3. Загрузите фото или опишите голосом / текстом что нужно
4. Ответьте на несколько вопросов (тип, стиль, освещение, инструмент)
5. Получите готовый промпт на английском
6. Нажмите **«Сгенерировать изображение»** — получите финальное фото
7. Сохраните результат в нужную категорию

## ⚙️ Требования

- Python 3.10+
- Аккаунт OpenAI с доступом к GPT-4o и DALL-E 3
- Telegram Bot Token

---

## 🔒 Безопасность

- Секреты хранятся только в `.env` (не в коде)
- `.env` добавлен в `.gitignore` — не попадёт в репозиторий

---

## 📌 Примечания

- Промпты генерируются **на английском** — так AI-инструменты работают точнее
- Интерфейс бота — **на русском**
- Сгенерированные изображения временно сохраняются в папку `downloads/`
- Сохранённые пользователем изображения хранятся в `saved_images/`
