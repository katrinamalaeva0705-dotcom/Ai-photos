# 📅 Telegram Календарь-Напоминалка

Личный Telegram-бот для управления задачами и напоминаниями. Без платных API — только Telegram!

## ✨ Что умеет

- ➕ Добавлять задачи с датой и временем (текстом или списком)
- ☀️ Присылать утреннее напоминание в 9:00 со списком задач на день
- ⏰ Напоминать за 1 час до каждой задачи
- 🗓 Показывать красивый календарь текущего месяца (картинкой)
- 📆 Показывать список ближайших задач
- 🗑 Удалять задачи

## 🚀 Запуск

### 1. Установить зависимости
```bash
pip install -r requirements.txt
```

### 2. Создать файл .env
```bash
cp .env.example .env
```
Вставить токен бота:
```
TELEGRAM_BOT_TOKEN=ваш_токен
```

### 3. Запустить
```bash
python main.py
```

## 📝 Как добавлять задачи

```
15 июня 10:00 Встреча с клиентом
20.06 14:30 Звонок партнёру
сегодня 18:00 Тренировка
завтра 09:00 Планёрка
15/07/2025 Конференция
```

## ⚙️ Настройки (config.py)

- `TIMEZONE` — ваш часовой пояс (по умолчанию `Europe/Moscow`)
- `MORNING_HOUR` / `MORNING_MINUTE` — время утреннего напоминания (по умолчанию 9:00)
